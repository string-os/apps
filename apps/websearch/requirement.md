# Requirements

## System Dependencies

| Package | Purpose | Install |
|---------|---------|---------|
| `curl` | HTTP requests (HN actions) | Pre-installed on most systems |
| `python3` | JSON processing (HN actions) | Pre-installed on most systems |

## Notes

- DuckDuckGo and Wikipedia use HTTP GET actions (no CLI tools needed)
- Hacker News actions use `curl` + `python3` for JSON processing
- No API keys required — all APIs are free and public
